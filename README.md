# Estonia E Residency Compliance Automator

Businesses in legal spend significant manual effort on: Estonia e-Residency Compliance Automator. This automation eliminates repetitive tasks, reduces errors, and accelerates turnaround.

## Category

Legal

## Agent Pipeline

| Agent | Role |
|-------|------|
| contract_parser | Parse contracts, extract key clauses, dates, parties |
| redline_detector | Identify non-standard terms, risky clauses, deviations from template |
| risk_assessor | Score contract risk, generate negotiation recommendations |
| compliance_checker | Check GDPR, SOC2, and regulatory compliance requirements |

## Tech Stack

- **Language:** Python 3.11+
- **Framework:** FastAPI
- **Agent Framework:** LangGraph
- **Testing:** pytest
- **CI/CD:** GitHub Actions
- **Containerization:** Docker
